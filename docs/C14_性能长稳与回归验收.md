## 2. 测试环境与前置

| 项 | 要求 |
| --- | --- |
| 环境 | E1（真双容器，L3/L4/L5 长稳）+ E6（时间加速）+ E7（单测） |

```bash
docker stats --no-stream astrbot napcat
docker exec astrbot sh -c 'wc -c /AstrBot/data/plugin_data/astrbot_plugin_guardian/guardian/{state.json,audit.jsonl}'
```

## 5.3 升级与回滚验证（B13 §13 / B14 §9）

```
升级（插件）：  cp data data.bak.<ts> -> git pull --ff-only -> up -d astrbot -> 查 [guardian] 启动
升级（宿主）：  cp -a /opt/astrobot /opt/astrobot.bak.<ts> -> install 脚本 -> daemon-reload -> restart timer
回滚（插件）：  git checkout <last_good_tag> -> restart astrbot
回滚（数据）：  mv data data.broken && mv data.bak.<ts> data -> restart astrbot（仅数据损坏时，会丢增量事件）
```

**回滚触发条件**：升级后 30 分钟内出现「连续重启 ≥ 3 次」「`/guardian status` 无响应」「事件循环阻塞告警」之一（C14-38）。

## 8. 回归建议

- **每次提交**：跑阶段 A（C03 + C06 回归段，< 30s）。
- **每次合并**：跑阶段 A + B（< 3min），并跑 C14-45 文档一致性。
- **每次发版**：跑阶段 A–D 全量 + C14-27..34（8 Gate）；E/F 视时间窗执行。
