## 1. 目标

| ID | 目标 | 判据 |
| --- | --- | --- |
| C13-G1 | 外部依赖崩溃时守护降级而非雪崩 | 探针 `UNKNOWN` + 零动作 + 单条告警 |
| C13-G2 | 重启风暴（R1）被冷却/熔断/退避三重拦截 | 窗口内重复动作被抑制 |
| C13-G3 | 自重启不中断在途请求（看门狗场景） | 请求与执行物理分离，结果可回写 |
| C13-G4 | 协议/返回畸形数据不导致崩溃 | 畸形 JSON/超时/401 均被兜底 |
| C13-G5 | 时钟/时区异常不误触发 | 回拨检测 + 顺延，无错误动作 |
| C13-G6 | LLM 幻觉/超大参数被运行时拦下 | 非法目标/命令/超长一律拒绝 |
| C13-G7 | 热重载/并发/在途动作一致 | 无重复动作、无任务残留 |
| C13-G8 | 资源耗尽（磁盘/内存/编码）不导致进程崩溃 | 降级 + 审计 + 不抛栈 |

## 2. 测试环境与前置

| 项 | 要求 |
| --- | --- |
| 环境 | E1（真双容器，L3/L4 注入）+ E2（无 docker 降级）+ E6（时间加速）+ E7（单测） |
| 隔离 | 专用项目名 `guardian-test`，禁止污染生产编排 `astrbotS` |
| 注入手段 | `docker kill`/`docker stop`/`docker pause`、`rm socket`、`chmod`、`iptables`/`tc`、`tmpfs` 填满、`SIGKILL` 进程、伪造请求文件 |
| 默认配置 | `dry_run=true`、`action_cooldown_sec=600`、`max_actions_per_hour=6`、`offline_confirm_rounds=2`、`self_restart_strategy=watchdog` |

**前置命令**：

```bash
docker compose -p guardian-test -f deploy/docker-compose.yml up -d
docker exec astrbot sh -c 'df -h /AstrBot/data; ls -l /var/run/docker.sock'
```

## 3. 测试数据与夹具

### 3.1 故障注入清单

| 类别 | 注入方式 | 观测点 |
| --- | --- | --- |
| daemon | `systemctl stop docker` / 重启中 | `docker_daemon` 探针、动作降级 |
| socket | `rm /var/run/docker.sock` / `chmod 000` / `:ro` 挂载 | 权限错误降级 |
| 容器 | `docker rename` / `docker rm -f` / `compose up` 重建 | 404 / 新 StartedAt |
| 网络 | `iptables -A INPUT -p tcp --dport 3000 -j DROP` | OneBot 不可达 |
| 协议 | stub 返回畸形 JSON / 超时 / 401 | 探针降级 |
| 磁盘 | 挂 1MB tmpfs 到数据目录 | 写失败降级 |
| 看门狗 | 停 timer / 改脚本权限 / 伪造请求 | `restart_result.json` |
| 时间 | `date -s` 回拨 / 改 `TZ` | `clock_skew` / 顺延 |

### 3.2 夹具清单

| 夹具 | 用途 |
| --- | --- |
| `stub_onebot` | 可控返回畸形 JSON / 超时 / 401 |
| `FakeDockerClient(raise=...)` | 注入 `DockerUnavailable` / 404 / 500 |
| `TimeWarp` / `freezegun` | 时钟回拨、DST、时间加速 |
| `corrupt_file` | 半截 `samples.json` / `state.json` |
| `readonly_dir` | 只读卷 |

## 6. 通过标准

- 第 4 节全部 P0（C13-01/02/03/04/06/07/09/10/11/12/14/15/18/19/20/21/23/24/25/26/29/30/31/32/33/34/35/36/37/39/40/41/42/43/44/45/46/48/49/53/54/55/56/57）通过。
- 第 5 节 P0（C13-58/59/60/63/67/70/74/77）通过。
- 外部依赖崩溃一律降级为 `UNKNOWN` + 零动作（C13-01/03/04/58/70）。
- 重启风暴三重拦截（C13-09/10/11/63）；本体自重启不中断在途（C13-13/14）。
- 协议/返回畸形数据不崩溃（C13-30..33）；LLM 幻觉与超大参数被拒（C13-34..39）。
- 时钟/时区异常不误触发（C13-26/27/28/76）；热重载/并发/在途一致（C13-40/41/42/77）。
- 事件循环阻塞被超时兜底（C13-43/44/69）；资源耗尽降级（C13-18/19/45/46/47）。
- 通知全失效不影响巡检（C13-48/49）；OOM 循环与扫码升级路径正确（C13-53/54）。
- dry_run 忘关与 30 天硬上限 + dry_run（C13-55/56）；等级配置非法回退（C13-57）。
