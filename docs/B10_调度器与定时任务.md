# B10 · 调度器与定时任务（Guardian 守护系统）

> 上游规格：`B00_项目总览与需求规格.md`（唯一权威）。模块名/配置键/数据模型均与 B00 一致：`core/scheduler.py`、`Profile`、`ActionSpec`、`check_interval`、`schedule.daily_restart_*`、`night_profile.maintenance_restart_cron`、`safety.action_cooldown_sec`。对应测试：`C10`；对应风险：R7、R10。

> **v0.2.0 增量（必读）**：新增两类定时任务——
> ① `guardian:qq`：QQ 登录态**独立**巡检，间隔 `qq.check_interval`（默认 1200 秒 / 20 分钟），与总巡检 `guardian:patrol` 解耦；
> ② `guardian:lifecycle`：生命周期等级推进评估，间隔可跟随 `check_interval`，负责等级判定、提示词注入刷新与 `force_sleep` 兜底（见 `B15`）。
> 三者共用同一 `Scheduler`，热重载时必须在 `terminate()` 中一并取消（R10）。

---

## 1. 目标

| 目标 | 判据 |
| --- | --- |
| G1 稳定 | 长跑不漂移、不漏跑、不因单任务异常停摆 |
| G2 可解释 | 任意时刻可答"每个任务下次何时跑、已跑几次、失败几次" |
| G3 可热重载 | `terminate()` 后旧定时器彻底消失，无重复巡检（R10） |
| G4 无依赖 | 仅标准库 `asyncio` + 自研 cron-lite（ADR D7），不引 `APScheduler`/`croniter` |
| G5 安全 | 定时触发的破坏性动作仍须穿过 `SafetyGuard`（B12） |
| G6 可测试 | cron 解析/匹配为纯函数，脱离事件循环即可断言（C10） |

非目标：分布式调度、持久化任务队列、秒级 cron（最小粒度 1 分钟）。

---

## 2. 调度需求

| # | 需求 | 形态 | 触发 | 配置来源 |
| --- | --- | --- | --- | --- |
| ① | 周期巡检 | `interval` | 每 N 秒 `HealthEngine.run_once(trigger="interval")` | `check_interval`，被档位覆盖 |
| ② | cron 定时重启 | `cron` | 到点执行"维护重启" | `schedule.daily_restart_cron`（默认 `0 4 * * *`）、`night_profile.maintenance_restart_cron` |
| ③ | 一次性延时任务 | `once` | `now+delay` 执行一次（如"5 分钟后重启本体"） | LLM/命令临时预约 |
| ④ | 夜间档位到期回落 | `once` | `night_until` 到点 `night -> normal` | `guardian_enter_night_watch(hours)` |

四类需求映射三个 API：`add_interval_job` / `add_cron_job` / `add_once_job`。**一个需求 = 一个 Job**，Job 互相隔离。

```
① interval ─┐ 每 60s  ┌───────────────────┐
② cron     ─┼────────►│ Scheduler: Job 表  │─► HealthEngine.run_once("interval")
③ once     ─┤ 04:00   └───────────────────┘
④ once     ─┘          每 Job 独立 Task，异常隔离；触发后一律经 SafetyGuard
```

## 3. 为什么自研 cron-lite（无第三方依赖）

| 方案 | 依赖面 | 5 字段 | 结论 |
| --- | --- | --- | --- |
| `croniter` | 第三方 PyPI | 是 | 否决：增供应链面 |
| `APScheduler` | 第三方 + tz 依赖链 | 是 | 否决：过重、线程/jobstore 冗余 |
| systemd timer | 需宿主机配置、跨容器通信 | 否 | 否决：与"插件自治"冲突（仅用于看门狗） |
| **自研 cron-lite** | **零依赖** | 是（`* , - /`+列表/步长） | **采用（ADR D7）** |

收益：供应链面为零；纯函数化便于 C10 断言；档位联动同进程完成；时区语义显式定义为**本地时区**，规避第三方默认 UTC 导致的 R7。代价：不支持 `@reboot`/`L`/`W`/`#`——刻意为之。

## 4. core/scheduler.py 完整代码

```python
"""core/scheduler.py - Guardian 轻量调度器（interval / cron-lite / once）。
纯 asyncio 零依赖；每 Job 独立 Task 异常隔离；cron 纯函数可测；misfire 不补跑；jitter 防同刻触发。
"""
from __future__ import annotations
import asyncio, logging, random, time
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from functools import lru_cache
from typing import Any, Awaitable, Callable, Optional

logger = logging.getLogger("guardian.scheduler")
JobFn = Callable[[], Awaitable[Any]]
_RANGES = {"minute": (0, 59), "hour": (0, 23), "day": (1, 31),
           "month": (1, 12), "dow": (0, 7)}   # cron 约定 0=Sunday，7 亦为 Sunday


class CronError(ValueError):
    pass


@dataclass(frozen=True)
class _CronSpec:
    minute: frozenset; hour: frozenset; day: frozenset
    month: frozenset; dow: frozenset; dom_raw: str; dow_raw: str


def _parse_field(raw: str, name: str) -> set:
    """解析单字段，支持 * , - / 及列表与步长。"""
    lo, hi = _RANGES[name]
    if not raw:
        raise CronError(f"cron 字段 {name} 为空")
    values: set = set()
    for part in raw.split(","):
        step, base = 1, part
        if "/" in part:
            base, _, s = part.partition("/")
            if not s.isdigit() or int(s) <= 0:
                raise CronError(f"步长非法: {part!r}")
            step = int(s)
        if base == "*":
            start, end = lo, hi
        elif "-" in base:
            a, _, b = base.partition("-")
            if not (a.isdigit() and b.isdigit()):
                raise CronError(f"区间非法: {part!r}")
            start, end = int(a), int(b)
        elif base.isdigit():
            start = end = int(base)
        else:
            raise CronError(f"字段取值非法: {part!r}")
        if start > end or start < lo or end > hi:
            raise CronError(f"区间非法或越界: {part!r}")
        values.update(range(start, end + 1, step))
    if not values:
        raise CronError(f"字段 {name} 解析为空")
    return values


@lru_cache(maxsize=256)
def parse_cron(expr: str) -> _CronSpec:
    """5 字段表达式 -> 集合规格（缓存）；非法即抛 CronError。"""
    parts = str(expr).split()
    if len(parts) != 5:
        raise CronError(f"cron 必须为 5 字段，收到 {len(parts)} 个: {expr!r}")
    minute, hour, day, month, dow = parts
    dv = _parse_field(dow, "dow")
    if 7 in dv:                             # 归一化 7 -> 0（周日）
        dv.discard(7); dv.add(0)
    f = _parse_field
    return _CronSpec(frozenset(f(minute, "minute")), frozenset(f(hour, "hour")),
                     frozenset(f(day, "day")), frozenset(f(month, "month")),
                     frozenset(dv), day, dow)


def cron_match(expr: str, dt: datetime) -> bool:
    """纯函数：判断 dt 是否命中 expr（秒/微秒不参与）。"""
    spec = parse_cron(expr)
    if dt.minute not in spec.minute or dt.hour not in spec.hour or dt.month not in spec.month:
        return False
    dow = (dt.weekday() + 1) % 7             # Python Mon=0..Sun=6 -> cron Sun=0..Sat=6
    dom_ok, dow_ok = dt.day in spec.day, dow in spec.dow
    if spec.dom_raw != "*" and spec.dow_raw != "*":
        return dom_ok or dow_ok              # 标准 cron：两者均限制时取 OR
    return dom_ok and dow_ok


def next_run(expr: str, after_dt: datetime, max_days: int = 366) -> datetime:
    """纯函数：strictly after after_dt 的下一个命中时间（分钟对齐）。"""
    cur = (after_dt + timedelta(minutes=1)).replace(second=0, microsecond=0)
    for _ in range(max_days * 24 * 60):
        if cron_match(expr, cur):
            return cur
        cur += timedelta(minutes=1)
    raise CronError(f"{expr!r} 在 {max_days} 天内无匹配时间点")


@dataclass
class Job:
    id: str; name: str; kind: str; fn: JobFn
    interval_sec: Optional[float] = None; cron: Optional[str] = None
    run_at: Optional[datetime] = None; next_run: Optional[datetime] = None
    jitter_sec: float = 0.0; misfire_grace_sec: float = 60.0
    runs: int = 0; failures: int = 0; skipped: int = 0
    last_run: Optional[float] = None; last_error: str = ""; enabled: bool = True
    task: Optional[asyncio.Task] = field(default=None, repr=False)


class Scheduler:
    """进程内异步调度器；所有方法须在事件循环内调用。"""
    def __init__(self, *, jitter_sec=0.0, misfire_grace_sec=60.0,
                 clock: Callable[[], datetime] = datetime.now) -> None:
        self._jobs: dict[str, Job] = {}
        self._j, self._g = float(jitter_sec), float(misfire_grace_sec)
        self._clock, self._closing = clock, False   # clock 可注入，便于测试
    def _now(self) -> datetime:
        return self._clock().replace(microsecond=0)
    def _register(self, job: Job) -> None:
        if job.id in self._jobs:
            self.cancel(job.id)              # 同名先取消，保证幂等
        self._jobs[job.id] = job
        job.task = asyncio.create_task(self._run_job(job), name=f"guardian:{job.id}")
    def _advance(self, job: Job) -> datetime:
        if job.kind == "interval":
            nxt = job.next_run + timedelta(seconds=job.interval_sec)
            return nxt if nxt > self._now() else self._now() + timedelta(seconds=job.interval_sec)
        return next_run(job.cron, self._now()) if job.kind == "cron" else job.next_run
    def _mk(self, job_id, fn, kind, *, name="", interval_sec=None, cron=None,
            run_at=None, jitter_sec=None, misfire_grace_sec=None) -> Job:
        return Job(job_id, name or job_id, kind, fn, interval_sec=interval_sec, cron=cron,
                   run_at=run_at, jitter_sec=self._j if jitter_sec is None else jitter_sec,
                   misfire_grace_sec=self._g if misfire_grace_sec is None else misfire_grace_sec)
    def add_interval_job(self, job_id, fn, interval_sec, *, name="", jitter_sec=None,
                         misfire_grace_sec=None, run_now=False) -> Job:
        if interval_sec <= 0:
            raise ValueError("interval_sec 必须 > 0")
        job = self._mk(job_id, fn, "interval", name=name, interval_sec=float(interval_sec),
                       jitter_sec=jitter_sec, misfire_grace_sec=misfire_grace_sec)
        now = self._now()
        job.next_run = now if run_now else now + timedelta(seconds=interval_sec)
        self._register(job); return job
    def add_cron_job(self, job_id, fn, expr, *, name="", jitter_sec=None,
                     misfire_grace_sec=None) -> Job:
        parse_cron(expr)                     # 提前校验，非法即抛
        job = self._mk(job_id, fn, "cron", name=name, cron=expr, jitter_sec=jitter_sec,
                       misfire_grace_sec=misfire_grace_sec)
        job.next_run = next_run(expr, self._now())
        self._register(job); return job
    def add_once_job(self, job_id, fn, delay_sec=None, *, at=None, name="",
                     misfire_grace_sec=0.0) -> Job:
        if at is None:
            if delay_sec is None:
                raise ValueError("add_once_job 需提供 delay_sec 或 at")
            at = self._now() + timedelta(seconds=delay_sec)
        job = self._mk(job_id, fn, "once", name=name, run_at=at, jitter_sec=0.0,
                       misfire_grace_sec=misfire_grace_sec)
        job.next_run = at
        self._register(job); return job
    def cancel(self, job_id: str) -> bool:
        job = self._jobs.pop(job_id, None)
        if job is None:
            return False
        job.enabled = False
        if job.task and not job.task.done():
            job.task.cancel()
        return True
    async def _run_job(self, job: Job) -> None:
        try:
            while not self._closing and job.enabled:
                delay = (job.next_run - self._now()).total_seconds()
                if delay > 0:
                    jitter = random.uniform(0, job.jitter_sec) if job.jitter_sec > 0 else 0.0
                    await asyncio.sleep(delay + jitter)          # jitter 抖动，避免同刻触发
                if self._closing:
                    break
                lag = (self._now() - job.next_run).total_seconds()
                if lag > job.misfire_grace_sec:      # misfire：不补跑，直接顺延
                    job.skipped += 1
                    logger.warning("job %s misfire: lag=%.1fs > grace=%.1fs, skip",
                                   job.id, lag, job.misfire_grace_sec)
                else:
                    await self._invoke(job)
                if job.kind == "once":
                    break
                job.next_run = self._advance(job)
        except asyncio.CancelledError:
            logger.debug("job %s cancelled", job.id); raise
        finally:
            job.task = None
    async def _invoke(self, job: Job) -> None:
        start = time.monotonic()
        try:
            await job.fn()
            job.runs, job.last_error = job.runs + 1, ""
        except asyncio.CancelledError:
            raise                            # 取消必须向上传播
        except Exception as exc:             # 异常隔离：单任务失败不停摆调度器
            job.failures += 1
            job.last_error = f"{type(exc).__name__}: {exc}"
            logger.exception("job %s failed (failures=%d)", job.id, job.failures)
        finally:
            job.last_run = time.time()
            logger.debug("job %s done in %.1fms", job.id, (time.monotonic() - start) * 1000)
    async def shutdown(self, timeout: float = 5.0) -> None:
        """严格取消所有任务并等待退出，避免热重载残留（R10）。"""
        self._closing = True
        pending = []
        for job in list(self._jobs.values()):
            job.enabled = False
            if job.task and not job.task.done():
                job.task.cancel(); pending.append(job.task)
        if pending:
            await asyncio.wait(pending, timeout=timeout)
        self._jobs.clear()
        logger.info("scheduler shutdown complete")

```

## 5. cron 纯函数可测设计

`cron_match(expr, dt)` 与 `next_run(expr, after_dt)` 不触碰事件循环、不读时钟（时间由参数传入），C10 可直接断言。

| 表达式 | 语义 | 关键断言 |
| --- | --- | --- |
| `0 4 * * *` | 每天 04:00 | `dt(…,4,0)` True |
| `*/5 * * * *` | 每 5 分钟 | 05 分 True，06 分 False |
| `0 9 * * 1-5` | 工作日 09:00 | 周一 True，周日 False |
| `0 0 * * 0` / `0 0 * * 7` | 周日（0 与 7 等价） | 两者匹配同一 dt |
| `0 0 13 * 5` | 13 日**或**周五（DOM/DOW 双限制 OR） | 命中其一即 True |
| `30 2,14 * * *` / `0 0-6/2 * * *` | 列表 / 区间+步长 | 对应分钟命中 |

## 6. 任务与档位的联动

切档位必须**重建 interval 任务**（间隔与是否暂停都变了，B00 §5）。

| 档位 | 巡检间隔 | interval 任务 |
| --- | --- | --- |
| `normal` | 60s（`check_interval`） | 启用 |
| `night` | 180s | 启用（重建，更省资源，静默 INFO） |
| `aggressive` | 20s | 启用（重建） |
| `maintenance` | 暂停 | **取消**（仅留 cron/once） |

```python
PROFILE_INTERVAL = {"normal": None, "night": 180, "aggressive": 20, "maintenance": None}

async def apply_profile(self, profile: str) -> None:
    base = int(self.cfg.get("check_interval", 60))
    self.scheduler.cancel("patrol"); self.scheduler.cancel("night_restart")
    iv = PROFILE_INTERVAL[profile]
    if iv is not None:                                    # 先停旧任务，再建新任务
        self.scheduler.add_interval_job("patrol", self._patrol, iv or base,
                                        name=f"巡检({profile})", jitter_sec=5.0)
    if profile == "night":                                # 夜间预约维护重启
        expr = self.cfg.get("night_profile", {}).get("maintenance_restart_cron", "0 4 * * *")
        self.scheduler.add_cron_job("night_restart", self._night_restart, expr,
                                    name="夜间维护重启", jitter_sec=60.0)
    self.state.set_profile(profile)
```

切换顺序与 B00 §4 一致：**停旧任务 → 等在途巡检结束（带超时）→ 建新任务 → 落盘 → 通知**。`cancel` 后旧任务不再进入 `_invoke`，但**已进入 `_invoke` 的那一次不会被强杀**，故须"等在途结束"，避免同一时刻两个巡检并发。

### 夜间档位到期自动回落（需求 ④）

```python
async def enter_night_watch(self, reason: str, hours: float) -> None:
    await self.apply_profile("night")
    until = datetime.now() + timedelta(hours=float(hours))
    self.state.update(night_until=until.isoformat())
    self.scheduler.add_once_job("night_expire", self._night_expire, at=until,
                                name="夜间档位回落", misfire_grace_sec=600.0)

async def _night_expire(self) -> None:
    if self.state.get("profile") == "night":              # 幂等：非 night 不动
        await self.apply_profile("normal")
        await self.notifier.notify_text("夜间守护已结束，回落 normal 档位")
```

`_night_expire` 的 `profile == "night"` 判断很关键：用户若在期间手动切 `aggressive`，到期任务**不得**改回 `normal`。

## 7. 幂等启动与热重载（R10）

R10 表现：热重载后旧实例的 `asyncio.Task` 未取消，与新实例**同时巡检** → 重复动作、重复告警、动作计数翻倍、可能提前触发熔断。三道防线：

```python
@filter.on_astrbot_loaded()
async def on_loaded(self):
    if getattr(self, "_started", False):                 # 防线 1：实例级幂等
        self.logger.warning("Guardian already started, skip"); return
    self._started = True
    await self.scheduler.shutdown()                      # 防线 2：先清空再重建
    self.scheduler = Scheduler(jitter_sec=5.0, misfire_grace_sec=60.0)
    await self.apply_profile(self.state.get("profile", "normal"))

async def terminate(self):
    await self.scheduler.shutdown(timeout=5.0)           # 防线 3：严格取消并等待
    await self.state.stop(); self._started = False
```

三道防线分别覆盖：同实例重复 `on_astrbot_loaded`（`_started` 守卫）、热重载残留任务（先 shutdown 再 new）、卸载/进程退出（`cancel()` + `await asyncio.wait(...)`）。

`shutdown` 内 `await asyncio.wait(pending, timeout=timeout)` 是关键：只 `cancel()` 不 `await` 会留下"已取消但仍在收尾"的任务，某些热重载实现下仍与新任务重叠。

## 8. 时钟与时区（R7）

cron 语义**永远以本地时区解释**。

| 层面 | 事实 | 处理 |
| --- | --- | --- |
| 宿主机 | Arch Linux，`timedatectl` 设 `Asia/Shanghai`（+08:00），NTP 同步 | 容器需继承 |
| 容器 | 默认 UTC！compose 未设 `TZ` 时容器内 `datetime.now()` 是 UTC | compose 显式 `TZ=Asia/Shanghai` + 挂载 `/etc/localtime:/etc/localtime:ro`（详见 B13） |
| 插件 | `datetime.now()` 取容器本地时区 | 与 `schedule.daily_restart_cron` 解释一致 |

**DST**：中国大陆自 1991 年起无夏令时，`Asia/Shanghai` 下**无 DST 跳变**。若部署于启用 DST 的时区：春季"跳过"的 1 小时（02:00→03:00）内若命中 02:30，该日该点**不存在**，`next_run` 自然跳次日；秋季"重复"的 1 小时可能触发两次，Guardian 以 `safety.action_cooldown_sec`（默认 600s）拦截第二次。

**时钟漂移**：NTP 校正使 `asyncio.sleep` 实际睡醒时刻偏差。Guardian 用 `_now()` 重取真实时间判定 misfire，不信任累计睡眠时长，故漂移只体现为"跳过/顺延"，不累积。启动时打印 `logger.info("clock: local=%s tz=%s utc_offset=%s", ...)` 供 `/guardian status` 与日志核对。

## 9. 定时重启的安全约束

**定时任务绝不绕过 `SafetyGuard`**。cron 到点不直接重启，而是构造 `ActionSpec` 走完整安全链（B12）：

```
cron 到点 → ActionSpec(kind="restart_container", target=白名单容器)
  → SafetyGuard.authorize(action, ctx(trigger="cron"))
        ├─ deny(cooldown/circuit/dry_run) → 记录 suppressed incident + 审计
        └─ allow → action.execute()  → AuditLog.append(...)
```

| 约束 | 规则 | 配置 |
| --- | --- | --- |
| 白名单 | 目标 ∈ (`managed` ∪ `allowed_containers`) | `containers.managed` / `safety.allowed_containers` |
| 受保护容器 | 本体 `astrbot` 需 `allow_self_restart=true` 且走 watchdog | `safety.protected_containers` |
| dry-run | `dry_run=true` 时仅记录不执行 | `dry_run`（默认 true） |
| 冷却 | 同目标 < `action_cooldown_sec` 抑制 | `safety.action_cooldown_sec` |
| 熔断 | 窗口内动作超限 → 只告警 | `safety.max_actions_per_hour` |
| 避让巡检 | 有巡检在途时等待其结束再执行 | 在途锁 |

避让实现：`_night_restart` 先检查 `self._patrol_lock.locked()`；若巡检在途则用 `add_once_job("night_restart_defer", ..., delay_sec=30.0)` 顺延，避免与巡检争用 Docker API。

**自重启（本体）**：默认 `safety.self_restart_strategy=watchdog`——写重启请求文件，由宿主机 systemd 单元执行 `docker compose restart astrbot`（ADR D3、B13）。若策略为 `disabled`，即使 cron 到点、即使 `allow_self_restart=true`，`SafetyGuard` 也拒绝。

## 10. 调度可观测

`Scheduler.status()` 返回结构化行，供 `/guardian status` 与 `guardian_health_report` 渲染：

| 字段 | 含义 | 用途 |
| --- | --- | --- |
| `id` / `name` / `kind` | 任务标识、人类可读名、类型 | 定位 |
| `next_run` / `in_sec` | 下次运行时间与倒计时 | "下次巡检还有 42s" |
| `runs` / `failures` / `skipped` | 成功、失败、misfire 跳过次数 | 长稳核对与时钟异常信号 |
| `last_error` | 最后一次错误摘要 | 排障 |

```
/guardian status
──────────────────────────────
[调度]
  patrol        巡检(night)     next=04:12:00 (+138s) runs=128 fail=0 skip=0
  night_restart 夜间维护重启     next=04:00:00        runs=0   fail=0 skip=0
  night_expire  夜间档位回落     next=07:30:00        runs=0   fail=0 skip=0
──────────────────────────────
```

CLI 侧直读 `self.scheduler.status()`；LLM 侧由 `guardian_health_report(scope="all")` 汇总调度段落（只读）。

## 11. 验收标准（对应 C10）

| 编号 | 验收项 | 判据 | 用例 |
| --- | --- | --- | --- |
| A1 | interval 准点 | 60s 任务 5 分钟内 runs ∈ [4,6] | C10-01 |
| A2 | cron 解析正确 | §5 全部表达式断言通过 | C10-02 |
| A3 | DOM/DOW OR 与周日 0/7 等价 | `0 0 13 * 5` 命中 13 日或周五；`* * 0` 与 `* * 7` 同一周日均命中 | C10-03/04 |
| A5 | once 只跑一次 | 延时 3s 任务 10s 内 runs == 1 | C10-05 |
| A6 | 异常隔离 | 注入抛异常任务，其它任务 runs 继续增长 | C10-06 |
| A7 | misfire 跳过 | 手动拨 `next_run` 到 5 分钟前，grace=60s，skipped+1 且不补跑 | C10-07 |
| A8 | jitter 生效 | 多任务 next_run 相同但触发时刻分散 | C10-08 |
| A9 | 档位联动 | 切 night 后 patrol 间隔变 180s；切 maintenance 后 patrol 被取消 | C10-09 |
| A10 | night_until 回落 | 到期后回 normal；手动改档位后到期任务不动它 | C10-10 |
| A11 | 热重载无残留（R10） | 连续 `on_loaded` 两次，patrol 任务数恒为 1 | C10-11 |
| A12 | shutdown 干净 | `terminate()` 后无存活 `guardian:*` 任务 | C10-12 |
| A13 | 定时重启走安全 | cron 重启在 dry-run 下零副作用、写审计 | C10-13 |
| A14 | 时区一致 | 容器 `TZ=Asia/Shanghai`，`0 4 * * *` 本地 04:00 触发 | C10-14 |
