## 2. 测试环境 / 前置

| 项 | 要求 |
| --- | --- |
| 宿主 | Arch Linux（`uname -r` ≥ 6.x），Docker ≥ 24，`docker compose` v2 |
| 容器 | `napcat`（`mlikiowa/napcat-docker:latest`）+ `astrbot`（`soulter/astrbot:latest`），`restart: unless-stopped` |
| 插件路径 | `src/astrbot_plugin_guardian/`（bind mount 到 `/AstrBot/data/plugins/astrbot_plugin_guardian`） |
| socket | `/var/run/docker.sock` 已挂载，`group_add` GID 与宿主 docker 组一致 |
| 时区 | 宿主 `timedatectl` 与容器 `TZ=Asia/Shanghai` 一致 |
| AstrBot | ≥ v4.25.1（`@register` 需 4 参） |
| 默认配置 | `enabled=true`、`mode=server`、`profile=normal`、`dry_run=true` |

**前置命令**：

```bash
docker compose -f deploy/docker-compose.yml up -d
docker compose ps                                  # 期望两容器 Up
docker exec astrbot ls -l /var/run/docker.sock     # 期望可见且属组 GID 正确
docker exec astrbot date                           # 期望 CST (+08:00)
docker logs --tail=200 astrbot | grep -i guardian  # 期望无 Traceback
```

## 4.2 启动时序（用于定位失败点）

```
1. AstrBot 扫描 plugins/ 目录 → 发现 astrbot_plugin_guardian/
2. 解析 metadata.yaml → 校验 astrbot_version（C01-03/04）
3. 安装 requirements.txt（C01-05）
4. 构造 GuardianPlugin(context, config) → _resolve_data_dir()（C01-20/26）
5. @filter.on_astrbot_loaded → _on_loaded()：enabled 判断 → 启动引擎（C01-01/19）
6. safety.check_startup() → WARN 清单（C01-09/10/11）
7. 注册命令 /guardian、/守护（C01-06/07/08）
8. 首次 startup 巡检（trigger=startup）（C01-30）
```

失败点定位：若第 2 步失败，WebUI 插件列表不显示；第 3 步失败，日志含 pip 错误；第 5 步失败，日志含 Traceback 但插件仍在列表。

## 6. 冒烟检查脚本

### 6.1 bash（宿主/容器内）

```bash
#!/usr/bin/env bash
# tests/smoke/guardian_smoke.sh —— C01 P0 冒烟
set -uo pipefail
fail=0
chk() { if eval "$2"; then echo "PASS $1"; else echo "FAIL $1"; fail=1; fi; }

chk "两容器 Up" "docker compose ps --format '{{.Name}} {{.Status}}' | grep -c Up | grep -q 2"
chk "socket 可见" "docker exec astrbot test -S /var/run/docker.sock"
chk "无 Traceback" "! docker logs --tail=300 astrbot 2>&1 | grep -q Traceback"
chk "guardian 启动行" "docker logs --tail=300 astrbot 2>&1 | grep -q '\[guardian\] started'"
chk "无 shell=True" "! grep -rn 'shell=True' src/ 2>/dev/null | grep -q ."
chk "无 requests" "! grep -rn 'import requests' src/ 2>/dev/null | grep -q ."
exit "$fail"
```

### 6.2 python（pytest 形态，假对象注入）

```python
# tests/smoke/test_c01_smoke.py
import pytest
from fixtures.fake_docker import FakeDockerClient

@pytest.mark.asyncio
async def test_status_format(guardian_plugin, fake_event):
    """/guardian status 回执含 mode/profile/dry_run（C01-07）。"""
    out = await guardian_plugin.handle_status(fake_event)
    text = out if isinstance(out, str) else out.text
    assert "mode=" in text and "profile=" in text and "dry_run=" in text

@pytest.mark.asyncio

    """无 docker 环境降级（C01-17）。"""

    res = await plugin.engine.run_once(trigger="startup")
    assert all(i.action is None for i in res)          # 零动作
```
