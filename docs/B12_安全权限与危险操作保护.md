## 1. 目标

| ID | 目标 | 判据 | 关联 |
| --- | --- | --- | --- |
| SG-1 | 任何副作用动作必须经 `SafetyGuard.authorize` 唯一入口授权 | 引擎无旁路调用 Action（B03 §6） | B00 §10-8 |
| SG-2 | 白名单强制：`restart_container`/`start_container` 目标 ∈ `managed ∪ allowed_containers` | 非白名单被拒 + 审计 | B00 §10-2 |
| SG-3 | 受保护容器（`astrbot`）需 `allow_self_restart=true` 且策略 ∈ `{watchdog, docker_api}` | 否则 deny | B00 §10-3 |
| SG-4 | 同目标冷却 + 窗口内每小时上限熔断（超限进只告警模式并升级 FATAL）；连续失败 N 次（默认 3）自动降级 `maintenance` | 冷却抑制、`circuit_open`、档位切换 | B00 §10-4/§10-6 |
| SG-5 | `dry_run=true` 时零副作用（返回 `allowed=True, dry_run=True`） | 容器状态零变化 | B00 §10-5 |
| SG-6 | 参数校验/规范化先于 action 层，拒绝含空格/分号/管道/反引号/`$()`/换行的输入；绝不 `shell=True`，恢复命令仅来自配置且启动校验前缀白名单 | 注入样例全被拒；无自由 shell 面 | B00 §10-8/§10-1、R9 |

非目标：不实现「任意 shell 执行工具」；不做用户/角色体系自建（复用 AstrBot 权限）；不做容器内 seccomp/AppArmor 策略定制（属宿主机加固，见 B13）。

## 2. 威胁模型（STRIDE 式）

| # | 威胁 | 场景 | 对策 | 落点 |
| --- | --- | --- | --- | --- |
| T1 | **LLM 幻觉**（Spoofing/Elevation） | LLM 依据用户模糊意图编造 `container="postgres"` 或 `kind="exec"`，试图重启无关服务 | ① 工具 docstring 枚举化 + 常量元组复核；② 运行时白名单二次校验；③ `kind` 枚举白名单；④ 破坏性工具要求管理员 + `confirm=true` 二次确认 | §3 `_whitelisted`、§4、B09 §4 |
| T2 | **恶意用户命令**（Tampering） | 普通成员发 `/guardian restart postgres --force` 或注入参数 | ① 命令层 `event.is_admin()` 拦截；② `validate_target` 正则拒 `--force`；③ argv 列表化，参数不拼接 | §4、§5 |
| T3 | **配置错误**（Tampering） | 运维把 `containers.managed` 填成 `["*"]`、把 `astrbot` 写进 `managed`、`action_cooldown_sec=0` | ① B02 `validate()` 启动即拒；② 启动安全自检输出 WARN 清单（§7）；③ 冷却下限约束 | §7、B02 §9 |
| T4 | **TOCTOU**（Race） | 授权时容器在白名单、执行时白名单被热改；或两轮巡检并发对同一目标动作 | ① 白名单在 `authorize` 内实时求值（非缓存）；② 进程内 `_inflight` + 冷却窗口；③ 授权即登记动作时间戳，失败不退还配额 | §3 `authorize`、B04 §8 |
| T5 | **命令注入**（Tampering） | 恢复命令字符串被拼进 shell：`docker restart $(cat /etc/passwd)` | ① 绝不用 `shell=True`；② 恢复命令来自配置且 `validate_command` 校验 argv 前缀 ∈ `{systemctl, docker, ros2, docker compose}`；③ 拒绝 shell 元字符 | §5 |
| T6 | **重启风暴**（DoS） | 容器重启后立即巡检→故障仍在→再重启，形成无限循环（R1） | ① 冷却 `action_cooldown_sec`；② 窗口熔断 `max_actions_per_hour`；③ 失败即停 → `maintenance`；④ 本体走看门狗（B13） | §3、§6 |
| T7 | **权限提升**（Elevation） | 通过 docker.sock 挂载在容器内获得等价宿主机 root，进而操作任意容器/执行 exec | ① 动作端点收口（仅 restart/start/inspect）；② 纵深防御 L5 宿主机再校验（B13 §9）；③ 最小权限：`docker-socket-proxy` 只读放行（§6.3） | §6、B13 |
| T8 | **审计缺失**（Repudiation） | 被抑制的动作/拒绝的回执不落盘，事后无法追责 | ① 审计不可关（B11 §5）：允许、抑制、拒绝三类均 `audit.append`；② 事件含 `suppressed + reason` | §3、B11 §5 |
| T9 | **通知劫持/风暴**（DoS/Info） | 伪造 UMO 或高频告警刷屏，淹没真实 FATAL（R8） | ① UMO 仅来自配置 `notify.umo_list`，不接受运行时注入；② 限流 + 去重 + 档位静默（B08）；③ 熔断后升级 FATAL 且只发一条 | §3 `trip`、B08 §7 |
| T10 | **凭证泄露**（Info Disclosure） | `access_token` 进入日志/审计/事件 `raw` | ① 仅从配置读取；② `mask_token()`；③ `audit.redact()` 统一脱敏 | B05 §10、B11 §9 |

**信任边界**：`(用户输入 | LLM 输出) → SafetyGuard → Action → (Docker API | 子进程 | 看门狗请求文件) → 宿主机`。跨越每个箭头都必须过校验；宿主机侧对请求文件**再校验一次**（不信任容器内输入）。

## 3. `core/safety.py` 完整代码

```python
# core/safety.py
"""Guardian 安全闸门：白名单 / 冷却 / 熔断 / dry-run / 参数校验 / 失败即停（B00 §10）。
唯一授权入口 SafetyGuard.authorize；授权与执行分离，动作层不得绕过本模块（B03 §6）。
"""
from __future__ import annotations
import re, time, unicodedata
from dataclasses import dataclass
from typing import Any
from astrbot.api import logger
from .models import ActionSpec

# ---------- 常量 ----------
TARGET_RE = re.compile(r"^[a-zA-Z0-9][a-zA-Z0-9_.-]*$")   # 容器名/节点名（B13 同款）
MAX_TARGET_LEN = 128
MAX_PARAM_STR = 256
MAX_PARAMS = 16
# 注入面：出现任一即拒绝（shell 元字符 / 控制字符 / 空白）
FORBIDDEN_SUBSTR = (" ", "\t", "\n", "\r", "\x00", ";", "|", "&", "`", "$", ">", "<", "*", "?", "'", '"', "\\")
ALLOWED_ACTION_KINDS = frozenset({
    "restart_container", "start_container", "qq_relogin", "ros2_restart", "set_profile", "notify"})
ALLOWED_PROFILES = frozenset({"normal", "night", "maintenance", "aggressive"})
ALLOWED_MODES = frozenset({"server", "ros2"})
# 恢复命令仅允许以下前缀（argv[0] 或 "docker compose" 双词前缀）
COMMAND_PREFIXES = ("systemctl", "docker", "ros2", "docker compose")
PROTECTED_STRATEGIES = frozenset({"watchdog", "docker_api"})
GLOBAL_RATE_KEY = "__global__"
DEFAULT_FAIL_THRESHOLD = 3


@dataclass(frozen=True)
class Decision:
    """一次授权结论。allowed=False 时 reason 面向用户/审计；code 供测试与统计。"""
    allowed: bool
    dry_run: bool = False
    reason: str = ""
    code: str = "ok"
    def __bool__(self) -> bool:
        return self.allowed


def normalize_text(value: str) -> str:
    """Unicode NFKC 归一化 + 去除首尾空白；用于消灭同形字符绕过（如全角分号）。"""
    return unicodedata.normalize("NFKC", str(value)).strip()


def validate_target(target: str) -> tuple[bool, str]:
    """容器名/节点名校验：字符集白名单 + 长度 + 注入面。返回 (ok, normalized)。"""
    norm = normalize_text(target)
    if not norm:
        return False, ""
    if len(norm) > MAX_TARGET_LEN:
        return False, norm
    if any(sub in norm for sub in FORBIDDEN_SUBSTR):
        return False, norm
    if not TARGET_RE.match(norm):
        return False, norm
    return True, norm


def validate_command(cmd: Any) -> tuple[bool, list[str] | str]:
    """恢复命令校验：必须为 argv 列表（或单条字符串），前缀 ∈ COMMAND_PREFIXES，无注入面。
    返回 (ok, argv|error)。绝不允许 shell=True 执行（B00 §10-1 / R9）。
    """
    if isinstance(cmd, str):
        argv = normalize_text(cmd).split()
    elif isinstance(cmd, (list, tuple)):
        argv = [normalize_text(x) for x in cmd]
    else:
        return False, "命令类型非法（需字符串或列表）"
    if not argv or not argv[0]:
        return False, "命令为空"
    if any(not tok for tok in argv):
        return False, "命令含空参数"
    for tok in argv:
        if any(sub in tok for sub in (";", "|", "&", "`", "$(", ">", "<", "\n")):
            return False, f"命令含注入字符: {tok!r}"
    joined = " ".join(argv[:2])
    if not (argv[0] in COMMAND_PREFIXES or joined in COMMAND_PREFIXES):
        return False, f"命令前缀不在白名单: {argv[0]!r}"
    return True, argv


class SafetyGuard:
    """动作授权闸门。构造注入 config / state；notifier 可选（用于 FATAL 升级）。"""
    def __init__(self, config: Any, state: Any, *, notifier: Any = None,
                 fail_threshold: int = DEFAULT_FAIL_THRESHOLD) -> None:
        self.config = config
        self.state = state
        self.notifier = notifier
        self.fail_threshold = int(fail_threshold)
        self._inflight: set[str] = set()
        self._tripped = False
    # ---------- 生命周期 ----------
    async def start(self) -> None:
        """从持久化状态恢复熔断/降级标志（R1：重启容器不得绕过熔断）。"""
        self._tripped = bool(await self.state.get_kv("safety.tripped", False))
        if self._tripped:
            logger.warning("[guardian] 启动即处于熔断只告警模式，需人工 /guardian reset")
    # ---------- 唯一授权入口 ----------
    async def authorize(self, action: ActionSpec, target: str = "",
                        ctx: dict[str, Any] | None = None) -> Decision:
        """授权一次动作。target 缺省取 action.target（B03 §6 调用 authorize(action, f.target, {...})）。"""
        ctx = ctx or {}
        target = normalize_text(target or action.target or "")
        # 0) 参数校验 / 规范化（先于一切副作用）
        bad = self._validate_action(action)
        if bad is not None:
            return bad
        ok, norm = validate_target(target)
        if not ok:
            return Decision(False, False, f"目标名非法或含注入字符: {target!r}", "invalid_target")
        target = norm
        # 1) 熔断优先：只告警模式下一律拒绝
        if self.is_tripped():
            return Decision(False, False, "熔断中（只告警模式），动作被拒，请人工介入", "circuit_open")
        # 2) 白名单（容器/节点类动作）
        if not self._whitelisted(action.kind, target):
            return Decision(False, False, f"{target} 不在白名单（managed ∪ allowed_containers）", "not_whitelisted")
        # 3) 受保护容器（本体）：需显式允许且策略可用
        if self._is_protected(target):
            if not bool(self.config.safety.allow_self_restart):
                return Decision(False, False, f"{target} 受保护，需 allow_self_restart=true",
                                "protected_requires_self_restart")
            if str(self.config.safety.self_restart_strategy) not in PROTECTED_STRATEGIES:
                return Decision(False, False, "自重启策略 disabled，禁止动作", "self_restart_strategy_disabled")
        # 4) 同目标冷却（可被 params.cooldown_key 覆盖，如 memory_leak）
        remain = await self._cooldown_remaining(action, target)
        if remain > 0:
            return Decision(False, False, f"{target} 处于冷却期（剩余 {remain:.0f}s）", "cooldown")
        # 5) 窗口内每小时上限 → 熔断并升级 FATAL
        if await self._would_exceed_rate():
            await self.trip(reason=f"动作数超过每小时上限 {self.config.safety.max_actions_per_hour}", target=target)
            return Decision(False, False, "熔断触发：动作数超上限，转只告警模式", "circuit_open")
        # 6) dry-run 短路：允许但标记 dry_run，动作层只记录不执行（B00 §10-5）
        if bool(self.config.dry_run):
            return Decision(True, True, "dry-run：仅记录，不执行副作用", "dry_run")
        # 7) 允许：登记动作时间戳（全局 + 目标），失败不退还配额（T4）
        await self._mark_action(target)
        return Decision(True, False, "允许", "ok")
    # ---------- 结果回写 / 失败即停 ----------
    async def record_result(self, ok: bool, target: str, *, detail: str = "") -> bool:
        """动作后回写；连续失败 >= fail_threshold → 降级 maintenance 并升级 FATAL。返回是否触发降级。"""
        if ok:
            await self.state.set_kv("safety.fail_streak", 0)
            return False
        streak = int(await self.state.get_kv("safety.fail_streak", 0)) + 1
        await self.state.set_kv("safety.fail_streak", streak)
        if streak < self.fail_threshold:
            logger.warning("[guardian] 动作失败 %d/%d target=%s: %s", streak, self.fail_threshold, target, detail[:160])
            return False
        self.state.set_profile("maintenance")          # 降级档位（暂停自动动作）
        await self.state.set_kv("safety.degraded", {"ts": time.time(), "streak": streak, "target": target})
        await self.trip(reason=f"连续 {streak} 次动作失败，已降级 maintenance 等待人工", target=target)
        logger.error("[guardian] 连续失败 %d 次 → 降级 maintenance（target=%s）", streak, target)
        return True
    # ---------- 熔断 ----------
    async def trip(self, *, reason: str, target: str = "") -> None:
        """进入只告警模式；持久化 + 升级 FATAL 通知（B00 §10-4）。幂等。"""
        first = not self._tripped
        self._tripped = True
        await self.state.set_kv("safety.tripped", True)
        await self.state.set_kv("safety.trip_info", {"ts": time.time(), "reason": reason, "target": target})
        if first:
            logger.error("[guardian] 熔断触发：%s（target=%s）", reason, target)
            await self._notify_fatal(f"【Guardian 熔断】{reason}；已进入只告警模式，请人工 /guardian reset。")
    def is_tripped(self) -> bool:
        return bool(self._tripped)
    async def reset(self, *, actor: str = "manual") -> None:
        """人工解除熔断（命令 /guardian reset，仅管理员）。"""
        self._tripped = False
        await self.state.set_kv("safety.tripped", False)
        await self.state.set_kv("safety.fail_streak", 0)
        await self.state.set_kv("safety.degraded", None)
        logger.info("[guardian] 熔断已由 %s 解除", actor)
    # ---------- 校验辅助 ----------
    def _validate_action(self, action: ActionSpec) -> Decision | None:
        """kind 枚举 + params 类型/长度/注入面校验；通过返回 None。"""
        kind = str(getattr(action, "kind", "") or "")
        if kind not in ALLOWED_ACTION_KINDS:
            return Decision(False, False, f"动作类型不在白名单: {kind!r}", "invalid_params")
        params = getattr(action, "params", None) or {}
        if not isinstance(params, dict) or len(params) > MAX_PARAMS:
            return Decision(False, False, "params 非字典或字段过多", "invalid_params")
        bad_str = lambda s: len(normalize_text(s)) > MAX_PARAM_STR or any(x in normalize_text(s) for x in FORBIDDEN_SUBSTR)
        for k, v in params.items():
            if any(x in normalize_text(k) for x in FORBIDDEN_SUBSTR):
                return Decision(False, False, f"params 键名非法: {k!r}", "invalid_params")
            if isinstance(v, str):
                if bad_str(v):
                    return Decision(False, False, f"params.{k} 值非法（长度或注入字符）", "invalid_params")
            elif isinstance(v, (int, float, bool)) or v is None:
                continue
            elif isinstance(v, (list, tuple)) and len(v) <= MAX_PARAMS:
                if any(isinstance(x, str) and bad_str(x) for x in v):
                    return Decision(False, False, f"params.{k} 列表元素非法", "invalid_params")
            else:
                return Decision(False, False, f"params.{k} 类型非法", "invalid_params")
        if kind == "set_profile" and str(params.get("profile", "")) not in ALLOWED_PROFILES:
            return Decision(False, False, f"档位非法: {params.get('profile')!r}", "invalid_params")
        if kind == "set_profile" and str(params.get("mode", "")) and str(params.get("mode")) not in ALLOWED_MODES:
            return Decision(False, False, f"模式非法: {params.get('mode')!r}", "invalid_params")
        return None
    def _whitelisted(self, kind: str, target: str) -> bool:
        """容器/节点类动作要求目标在白名单；set_profile/notify 等无目标动作直接放行。"""
        if kind in ("set_profile", "notify"):
            return True
        if kind == "ros2_restart":
            return target in (getattr(self.config.ros2, "node_restart_commands", {}) or {})
        return target in set(self.config.action_allowlist)   # B02：managed ∪ allowed_containers
    def _is_protected(self, target: str) -> bool:
        return target in set(getattr(self.config.safety, "protected_containers", []) or [])
    def _cooldown_sec_for(self, action: ActionSpec) -> int:
        """冷却时长：params.cooldown_key == memory_leak 时用 memory.leak_cooldown（B06）。"""
        if str((action.params or {}).get("cooldown_key", "")) == "memory_leak":
            return int(getattr(self.config.memory, "leak_cooldown", 3600))
        return int(self.config.safety.action_cooldown_sec)
    async def _cooldown_remaining(self, action: ActionSpec, target: str) -> float:
        last = float(await self.state.get_kv(f"action.last.{action.kind}.{target}", 0.0))
        return max(0.0, self._cooldown_sec_for(action) - (time.time() - last))
    async def _would_exceed_rate(self) -> bool:
        win = float(self.config.safety.circuit_breaker_window_sec)
        marks = [t for t in self.state.circuit_window(GLOBAL_RATE_KEY) if time.time() - t <= win]
        return len(marks) >= int(self.config.safety.max_actions_per_hour)
    async def _mark_action(self, target: str) -> None:
        now, win = time.time(), float(self.config.safety.circuit_breaker_window_sec)
        for key in (GLOBAL_RATE_KEY, target):        # 全局窗口 + 目标窗口
            marks = [t for t in self.state.circuit_window(key) if now - t <= win] + [now]
            self.state.set_circuit_window(key, marks)
        for kind in ALLOWED_ACTION_KINDS:            # 同目标冷却时间戳，防「换 kind 绕过」
            await self.state.set_kv(f"action.last.{kind}.{target}", now)
    async def _notify_fatal(self, text: str) -> None:
        if self.notifier is None:
            return
        try:
            await self.notifier.push_system(text, severity="fatal")
        except Exception as exc:  # noqa: BLE001 通知失败不影响安全判定
            logger.error("[guardian] FATAL 通知失败: %s", exc)
    # ---------- 启动安全自检 ----------
    async def check_startup(self) -> list[str]:
        """返回 WARN 清单（空表示无告警）。不抛异常，仅提示（R2 / T3）。"""
        import os
        warns: list[str] = []
        sock = str(getattr(self.config.docker, "socket_path", "/var/run/docker.sock"))
        if not os.path.exists(sock):
            warns.append(f"[WARN] docker socket 不存在：{sock}（动作类功能不可用，见 B13 §4）")
        elif not os.access(sock, os.W_OK):
            warns.append(f"[WARN] docker socket 不可写：{sock}（检查 group_add / GID，见 B13 §4）")
        if not set(self.config.action_allowlist):
            warns.append("[WARN] 动作白名单为空，任何 restart/start 都会被拒")
        if bool(self.config.dry_run):
            warns.append("[INFO] dry_run=true：当前只观测不执行，确认稳定后手动关闭（B00 §10-5）")
        if bool(self.config.safety.allow_self_restart):
            warns.append(f"[WARN] allow_self_restart=true 策略={self.config.safety.self_restart_strategy}："
                         "本体可被自动重启，请确认已部署看门狗（B13）")
        allowed = set(self.config.action_allowlist)
        for name in set(getattr(self.config.safety, "protected_containers", []) or []):
            if name not in allowed:
                warns.append(f"[WARN] 受保护容器 {name} 不在动作白名单中：只能被显式允许的动作命中")
        if int(self.config.safety.action_cooldown_sec) < 60:
            warns.append("[WARN] action_cooldown_sec < 60，冷却过短易形成重启风暴（R1）")
        return warns
```

> 兼容说明：B03 §6 调用 `self.safety.authorize(f.suggested_action, f.target, {"trigger": "scan"})`，与本文 `authorize(action, target="", ctx=None)` 签名一致；`target` 缺省时回退 `action.target`。动作执行后由引擎调用 `safety.record_result(ok, target, detail=...)` 完成失败即停闭环（B03 §6 的 `_handle_finding` 末尾）。

## 4. 权限模型（三层收口）

| 层 | 校验点 | 实现 | 拒绝行为 |
| --- | --- | --- | --- |
| L-C 命令层（人） | `/guardian restart`、`/guardian mode`、`/guardian profile`、`/guardian reset` | `event.is_admin()`（回退 `event.role in {"admin","owner"}`） | 回执「需要管理员权限」+ 审计 `actor` |
| L-T 工具层（LLM） | `guardian_restart_container` / `guardian_set_mode` / `guardian_set_profile` | `llm_tools.require_admin`（B00 §7，默认 true）；`_require_admin(event, tool)` 统一助手 | 回执拒绝话术 + 审计 |
| L-D 破坏性二次确认 | 重启类工具 | 首次调用 `confirm=false` 只回确认提示，`confirm=true` 才进入 `SafetyGuard` | 回执「确认执行？」 |
| L-S 安全层（所有人） | 全部动作 | `SafetyGuard.authorize` | 抑制 + 审计 + 通知 |
| L-H 宿主机（最后防线） | 看门狗请求文件 | `guardian-watchdog.sh` 再校验 `target ∈ GUARDIAN_ALLOWED_TARGETS` | `outcome=denied`（B13 §9） |

```python
# tools/llm_tools.py（节选）：统一管理员校验
async def _require_admin(self, event, tool: str):
    if not bool(getattr(self.config.llm_tools, "require_admin", True)):
        return None
    try:
        ok = bool(event.is_admin())                       # AstrBot 官方权限判定
    except Exception:                                     # noqa: BLE001 回退 role
        ok = str(getattr(event, "role", "")) in ("admin", "owner")
    return None if ok else event.plain_result(f"[Guardian] 拒绝：{tool} 需要管理员权限。")
```

要点：**权限只是第一道闸门，不等于授权**——管理员仍需通过 `SafetyGuard` 的白名单/冷却/熔断/dry-run 四重约束；非管理员即使通过白名单也会在 L-T 被拦。

## 5. 命令注入防护

| 规则 | 做法 | 反例（被拒） |
| --- | --- | --- |
| 绝不用 `shell=True` | 一律 `asyncio.create_subprocess_exec(*argv)`（B07 `utils/shell.py`） | `subprocess.run(cmd, shell=True)` |
| argv 列表化 | 命令以列表承载，参数逐个传递，不做字符串拼接 | `f"docker restart {name}"` |
| 恢复命令白名单映射 | 仅 `config.ros2.node_restart_commands` 中的值可执行；键为节点名，值为 argv | 从消息文本取命令 |
| 前缀白名单 | 启动时 `validate_command` 校验前缀 ∈ `{systemctl, docker, ros2, docker compose}` | `rm -rf /`、`bash -c ...` |
| 目标名正则 | `^[a-zA-Z0-9][a-zA-Z0-9_.-]*$`，拒绝 `--force`/`$(...)`/空白 | `napcat; rm -rf /` |
| 元字符拒绝 | 逐 token 检查 `; \| & \` $ ( ) > < \n` | `docker restart $(id -u)` |
| 无 shell 展开 | 不经过 shell，`$VAR`/通配符不展开 | `docker restart *` |

```python
# 启动期校验（main.py 加载时调用）：恢复命令映射必须全部合法，否则禁用该项并告警
for node, cmd in (self.config.ros2.node_restart_commands or {}).items():
    ok, argv = validate_command(cmd)
    if not ok:
        logger.error("[guardian] ros2 恢复命令非法 node=%s cmd=%r -> %s（已禁用）", node, cmd, argv)
        self._disabled_restart_nodes.add(node)
```

## 6. 最小权限原则

### 6.1 现状风险
直挂 `/var/run/docker.sock` 等价把宿主机 root 交给容器（T7）：攻击者可 `exec` 任意容器、挂载宿主机根目录、创建特权容器。Guardian 自身只需 **restart / start / inspect** 三个端点。

### 6.2 收口动作面（当前默认）
- 动作层只暴露 `POST /containers/{name}/restart`、`POST /containers/{name}/start`、`GET /containers/{name}/json`（B04 §3），无 `exec`/`stop`/`kill` 的通用封装。
- 目标名过 `validate_target` 正则，杜绝路径穿越（如 `../..`）。
- 纵深防御：宿主机看门狗再校验白名单（B13 §9 L5）——即使容器被攻破改请求文件，也无法诱导宿主机执行任意命令。

### 6.3 `docker-socket-proxy`（最小权限替代，Roadmap）
```yaml
# 技术预览：本期未纳入正式交付（B13 §11）
services:
  docker-socket-proxy:
    image: tecnativa/docker-socket-proxy:latest
    container_name: guardian-socket-proxy
    restart: unless-stopped
    environment:
      CONTAINERS: "1"    # 只放行容器查询
      POST: "1"          # 允许 POST（restart/start 需要）
      RESTART: "1"       # 只允许 restart
      START: "1"         # 只允许 start
      EXEC: "0"          # 显式关闭 exec / 镜像 / 卷 / 网络 / 认证
      IMAGES: "0"
      VOLUMES: "0"
      NETWORKS: "0"
      AUTH: "0"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro
    networks: [guardian-net]
```
启用后 `utils/dockerclient.py` 需支持 `DOCKER_HOST=tcp://guardian-socket-proxy:2375`（B13 §11）。**收益**：把「全量 Docker API」收窄为「容器 restart/start/inspect」，即使插件被 RCE 也无法 exec 或操纵卷/网络。

### 6.4 其他最小权限项
| 项 | 做法 |
| --- | --- |
| 文件权限 | 重启请求/结果文件 `0660`，仅 `astrbot` 容器可写（B13 §9） |
| 网络 | 仅 `guardian-net` 内部网络；NapCat WebUI `6099` 不公网暴露（B13 §12） |
| 依赖 | 仅 `aiohttp`（B00 §7），无 `requests`/`paramiko` 等额外攻击面 |
| 进程 | 看门狗单元 `NoNewPrivileges=true` + `ProtectSystem=strict`（B13 §7.3） |

## 7. 启动安全自检

`main.py` 加载后、进入巡检循环前调用 `safety.check_startup()`，把 WARN 清单写入日志并（可选）推送一条汇总给管理员：

```python
warns = await safety.check_startup()
for w in warns:
    logger.warning("[guardian] 安全自检 %s", w)
if warns:
    await notifier.push_system("【Guardian 启动自检】\n" + "\n".join(warns), severity="warn")
```

自检项与判据：

| 检查项 | 判据 | 不通过后果 |
| --- | --- | --- |
| socket 存在性 | `os.path.exists(docker.socket_path)` | 动作类全部不可用（R2） |
| socket 可写性 | `os.access(sock, os.W_OK)` | restart/start 报 `Permission denied` |
| 白名单非空 | `action_allowlist` 非空 | 所有 restart/start 被拒（T3） |
| `dry_run` | 提示当前值 | 忘了关闭 → 动作永不生效（B14 Playbook） |
| `allow_self_restart` | 若 true 提示已开 | 未部署看门狗时自重启中断在途请求（R1） |
| 受保护容器存在性 | `protected_containers` 中名字是否在 `action_allowlist` | 受保护容器永不可被自动动作命中 |
| 冷却下限 | `action_cooldown_sec ≥ 60` | 过短易风暴 |
| 熔断阈值 | `max_actions_per_hour ≤ 12` | 过宽失去保护 |
| 恢复命令合法性 | 全部 `validate_command` 通过 | 非法项禁用 + 告警（R9） |

## 8. 拒绝话术模板（面向用户的中文回执）

统一前缀 `[Guardian]`，说明「拒绝原因 + 如何解除」，不泄露内部路径/凭据。

| code | 话术模板 |
| --- | --- |
| `not_whitelisted` | `[Guardian] 已拒绝：容器「{target}」不在守护白名单内，不会对它执行重启。可操作的目标：{allowed_list}。如需纳入请修改 containers.managed 或 safety.allowed_containers。` |
| `protected_requires_self_restart` | `[Guardian] 已拒绝：{target} 是受保护容器（本体），需显式开启 safety.allow_self_restart 且使用 watchdog/docker_api 策略后才可重启。` |
| `self_restart_strategy_disabled` | `[Guardian] 已拒绝：当前自重启策略为 disabled，禁止对 {target} 执行动作。请人工处理或调整 safety.self_restart_strategy。` |
| `cooldown` | `[Guardian] 已抑制：{target} 处于动作冷却期（剩余约 {remain}s）。冷却用于防止重启风暴，请稍后再试。` |
| `circuit_open` | `[Guardian] 已熔断：窗口内动作次数已达上限（{max_actions_per_hour}/窗口），系统进入只告警模式，需管理员执行 /guardian reset 解除。` |
| `invalid_target` | `[Guardian] 已拒绝：目标名「{target}」非法（只允许字母/数字/下划线/点/短横，且不含空格或 shell 符号）。` |
| `invalid_params` | `[Guardian] 已拒绝：参数不合法（{detail}）。请检查动作类型与参数取值。` |
| `admin_required` | `[Guardian] 已拒绝：该操作需要管理员权限。` |

## 10. 验收标准（对应 G-SAFETY）

**Gate `G-SAFETY`（B00 §13）**：非白名单容器重启被拒；dry-run 下零副作用；熔断生效。
