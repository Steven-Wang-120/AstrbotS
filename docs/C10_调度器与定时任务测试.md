## 3. 测试数据与夹具

### 3.1 cron 表达式断言表（B10 §5）

| 表达式 | 语义 | 关键断言 |
| --- | --- | --- |
| `0 4 * * *` | 每天 04:00 | `dt(...,4,0)` True，`dt(...,4,1)` False |
| `*/5 * * * *` | 每 5 分钟 | 05 分 True，06 分 False |
| `0 9 * * 1-5` | 工作日 09:00 | 周一 True，周日 False |
| `0 0 * * 0` / `0 0 * * 7` | 周日（0 与 7 等价） | 两者匹配同一 dt |
| `0 0 13 * 5` | 13 日**或**周五（DOM/DOW 双限制 OR） | 命中其一即 True |
| `30 2,14 * * *` | 列表 | 02:30/14:30 True |
| `0 0-6/2 * * *` | 区间+步长 | 0/2/4/6 时 True |
| `60 * * * *` | 越界（分钟 > 59） | 抛 `CronError` |
| `* * * *` | 字段数不足 | 抛 `CronError` |
| `0 0 * * 8` | dow 越界 | 抛 `CronError` |

## 5.1 cron 纯函数可测设计（B10 §5）

`cron_match(expr, dt)` 与 `next_run(expr, after_dt)` 不触碰事件循环、不读时钟（时间由参数传入），故 C10 可直接断言：

| 表达式 | 语义 | 关键断言 | 用例 |
| --- | --- | --- | --- |
| `0 4 * * *` | 每天 04:00 | `dt(...,4,0)` True | C10-01/06 |
| `*/5 * * * *` | 每 5 分钟 | 05 分 True，06 分 False | C10-02/07 |
| `0 9 * * 1-5` | 工作日 09:00 | 周一 True，周日 False | C10-01 |
| `0 0 * * 0` / `0 0 * * 7` | 周日（0 与 7 等价） | 两者匹配同一 dt | C10-03/53 |
| `0 0 13 * 5` | 13 日**或**周五（DOM/DOW 双限制 OR） | 命中其一即 True | C10-04 |
| `30 2,14 * * *` / `0 0-6/2 * * *` | 列表 / 区间+步长 | 对应时刻命中 | C10-02/54 |

## 5.2 任务与档位联动（B10 §6）

| 档位 | 巡检间隔 | interval 任务 | 用例 |
| --- | --- | --- | --- |
| `normal` | 60s（`check_interval`） | 启用 | C10-09 |
| `night` | 180s | 启用（重建，更省资源，静默 INFO） | C10-16 |
| `aggressive` | 20s | 启用（重建） | C10-18 |
| `maintenance` | 暂停 | **取消**（仅留 cron/once） | C10-17 |

**切换顺序**（B00 §4）：停旧任务 → 等在途巡检结束（带超时）→ 建新任务 → 落盘 → 通知（C10-43）。

## 5.3 幂等启动与热重载三道防线（R10）

```
防线 1  _started 守卫        -> 同实例重复 on_astrbot_loaded 直接 skip（C10-22）
防线 2  先 shutdown 再 new   -> 清空旧任务后重建（C10-21）
防线 3  terminate() 严格取消 -> cancel() + await asyncio.wait(...)（C10-23/24/47）
```

> 只 `cancel()` 不 `await` 会留下"已取消但仍在收尾"的任务，某些热重载实现下仍与新任务重叠。

## 5.4 时钟与时区（R7）

| 层面 | 事实 | 处理 | 用例 |
| --- | --- | --- | --- |
| 容器 | 默认 UTC（未设 `TZ`） | compose 显式 `TZ=Asia/Shanghai` | C10-30 |
| DST | Shanghai 无 DST | 非 Shanghai 时区春季跳次日、秋季第二次被冷却拦截 | C10-38/39 |
| 漂移 | NTP 校正 `asyncio.sleep` | 用 `_now()` 重取真实时间判 misfire | C10-36 |

## 6. 通过标准

- 第 4 节全部 P0（C10-01/02/03/04/06/09/12/14/15/16/17/19/20/21/22/23/24/25/26/28/29/30）通过。
- 第 5 节 P0（C10-34/43/45/47）通过。
- cron 纯函数断言全绿（C10-01..08）；非法表达式抛 `CronError`（C10-01/32/33）。
- interval 节拍准、misfire 不补跑（C10-09/14）。
- 档位联动正确（C10-16/17/18）；`night_until` 回落幂等（C10-19/20）。
- **R10 热重载无残留**：`guardian:patrol` 恒为 1（C10-21/22）；`terminate()` 干净（C10-23/24/47）。
- 定时重启走 `SafetyGuard` 且 dry-run 零副作用（C10-25/26）。
- `guardian:qq` 20 分钟独立节拍且与 `guardian:patrol` 解耦（C10-28/29）。
- 时区一致（C10-30）；`G-STABILITY` 无重复巡检、无时钟误触发。
