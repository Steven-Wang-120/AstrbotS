## 1. 目标

| ID | 目标 | 判据 |
| --- | --- | --- |
| C02-G1 | 默认配置可读，缺失键回落默认 | `from_astrbot_config({})` 不抛异常，全键有值 |
| C02-G2 | 每个配置键的类型/范围校验正确 | `validate()` 对非法值返回明确错误 |
| C02-G3 | 非法值安全回退且不崩溃 | 强转失败回落默认，热更新失败保留旧视图 |
| C02-G4 | `lifecycle.levels` 结构合法 | 非空、`after_hours` 升序、`max_uptime_hours` ≥ 最大阈值 |
| C02-G5 | 模式切换 7 步流程完整、无泄漏 | 停表/等在途/重置冷却/落盘/通知均生效 |
| C02-G6 | 配置热更新生效矩阵正确 | 热生效键即时生效；需重载键重载后生效 |
| C02-G7 | 运行时覆盖状态跨重启保持 | `mode`/`profile` 重启后覆盖配置默认 |

## 3. 测试数据与夹具

| 夹具 | 用途 |
| --- | --- |
| `cfg_raw(...)` 构造器 | 按 key 覆盖生成 AstrBotConfig 原始 dict |
| `fake_state` | 记录 `mode`/`profile`/`cooldown`/`circuit` 写入 |
| `fake_notifier` | 断言切换通知次数与文本 |
| `timewarp` | 控制 `wait_idle` 超时与冷却窗口 |
| `levels_cases` | `lifecycle.levels` 的合法/非法样本集 |

**合法 levels 样本**（默认 L0–L4，B15 §2.1）：

```json
{"lifecycle": {"levels": [
  {"id": "L0", "name": "常规", "after_hours": 0, "prompt": "", "action": "none"},
  {"id": "L1", "name": "I 级 · 轻提醒", "after_hours": 168, "prompt": "...", "action": "notify"},
  {"id": "L2", "name": "II 级 · 建议休息", "after_hours": 360, "prompt": "...", "action": "notify"},
  {"id": "L3", "name": "III 级 · 准备睡眠", "after_hours": 600, "prompt": "...", "action": "arm_sleep"},
  {"id": "L4", "name": "IV 级 · 强制睡眠", "after_hours": 720, "prompt": "...", "action": "force_sleep"}
]}}
```

**非法样本**：`levels=[]`、`after_hours` 降序（`[0,360,168]`）、`action="sleep"`（非枚举）、`max_uptime_hours=100`（< 最大 `after_hours`）、`sleep_targets=["unknown"]`（不在白名单）、`sleep_duration_min=999`（越界）、`inject_mode="bogus"`。

## 4.1 模式切换 7 步流程（B02 §7）验证细则

| 步 | 动作 | 断言点 | 对应用例 |
| --- | --- | --- | --- |
| 1 | 停表 `scheduler.pause()` | 切换期间无新 tick 进入 | C02-26 / C02-29 |
| 2 | 等待在途 `await engine.wait_idle(timeout=30)` | 在途结束或超时记 WARN | C02-29 / C02-45 |
| 3 | 释放旧模式 `await probe.close()` | 旧探针连接/会话关闭 | C02-27 |
| 4 | 构建新模式 `create_mode(...)` | `_probes/_actions` 被替换 | C02-27 |
| 5 | 重置冷却/熔断 `safety.reset()` | `cooldown`/`breaker` 清空 | C02-30 |
| 6 | 落盘 `state.set("mode")` + `save()` | `state.json` 更新 | C02-28 |
| 7 | 通知 + 起表 `notifier.dispatch` + `scheduler.resume` | 回执 1 条 + 间隔按档位 | C02-26 / C02-27 |

## 4.3 `lifecycle.levels` 校验规则（B15 §8）

| 规则 | 失败行为 | 用例 |
| --- | --- | --- |
| `levels` 非空 | 回退默认 L0–L4 并告警 | C02-19 |
| `after_hours` 严格升序（允许相等） | 自动排序 + 告警 | C02-20 / C02-49 |
| `max_uptime_hours` ≥ 最大 `after_hours` | 取较大值 + 告警 | C02-21 |
| `action ∈ {none,notify,arm_sleep,force_sleep}` | 非法回退 `none` + 告警 | C02-22 |
| `sleep_targets ⊆ 动作白名单` | 非法剔除 + 告警；空则睡眠不可用 | C02-23 |
| `sleep_duration_min ∈ [0,120]` | 越界截断 | C02-24 |
| `inject_mode ∈ {extra_user_content, system_prompt}` | 回退 `extra_user_content` | C02-25 |
