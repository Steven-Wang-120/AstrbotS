## 1. 目标

| ID | 目标 | 判据 |
| --- | --- | --- |
| C08-G1 | 一次巡检结果可靠送达每个有效 UMO | 每个 UMO 恰好收到 1 条聚合消息 |
| C08-G2 | 不刷屏 | 同目标同状态在 `notify.rate_limit_sec` 窗口内只推一次 |
| C08-G3 | 只在状态跃迁时告警 | `OK→CRIT` 告警、`CRIT→CRIT` 静默、`CRIT→OK` 恢复通知 |
| C08-G4 | 档位可静默 | `night` 静默低于 `mute_below_severity`；`maintenance` 全静默 |
| C08-G5 | 推送失败不拖垮引擎 | 异常被吞并降级日志，巡检主流程零中断 |
| C08-G6 | 每次通知可追溯 | 投递/跳过/失败/UMO 失效均写审计 |
| C08-G7 | 探针与通知解耦 | 探针只发事件，不认识 UMO 与消息模板 |
| C08-G8 | 多事件聚合 | 一轮多 Finding 只渲染 1 条消息 |

## 5.1 通知过滤短路顺序（B08 §4 `_pass_filter`）

一轮 Incident 依下列顺序短路，**先到先得**，命中即抑制并写 `notify.skipped`：

| 顺序 | 条件 | suppress_reason | 用例 |
| --- | --- | --- | --- |
| 1 | `profile == maintenance` | `profile_maintenance_mutes_all` | C08-17 |
| 2 | `severity < notify.min_severity` | `below_min_severity` | C08-02 |
| 3 | `profile == night` 且 `severity < mute_below_severity` | `night_mute` | C08-15 |
| 4 | 无状态跃迁（`prev == cur`，或首次为 OK） | `no_state_transition` | C08-07/09 |
| 5 | 同 `probe|target|status` 在 `rate_limit_sec` 窗口内 | `rate_limited` | C08-04/06 |
| 6 | 全部通过 | （推送） | C08-01/10/11 |

> 顺序不可交换：若先判跃迁再判 maintenance，会导致 maintenance 下仍更新跃迁基线，造成恢复后误判。

## 5.2 投递可靠性降级链（B08 §11）

```
_send(umo, text)
  ├─ attempt 1 -> ok    -> _umo_fail[umo]=0, return True
  ├─ attempt 1 -> fail  -> log.warning
  ├─ attempt 2 -> ok    -> 清零, return True
  └─ attempt 2 -> fail  -> _umo_fail[umo] += 1
        ├─ 计数 < 3  -> log.error("[降级] 全文") + return False
        └─ 计数 >= 3 -> audit(notify.umo_invalid) + 后续跳过该 UMO
```

**铁律**：通知失败**绝不**向上抛，`dispatch` 返回值只用于审计与指标，不影响巡检主流程（C08-19/49）。

## 5.3 消息模板与字段契约（B08 §5）

| 模板 | 触发 | 关键字段 | 用例 |
| --- | --- | --- | --- |
| 健康快照 | `/guardian status`、`guardian_health_report` | 容器/内存/QQ/ROS2 各一行 | C09-23 |
| 事件告警 | `incident.recorded`（单条） | severity、probe/target、status、message、action | C08-23/47 |
| 动作回执 | `action.result` / Incident 带 result | kind、target、成功/失败、detail、elapsed_ms | C08-14/49 |
| 启动/停止 | `plugin.started` / `plugin.stopped` | profile、mode、探针数 | C08-25/26 |

**审计联动**（B08 §12）：`notify.sent`（至少一个 UMO 成功）、`notify.failed`（全部失败）、`notify.skipped`（被过滤/静默/限流）、`notify.umo_invalid`（连续失败达阈值）。四类均不可关（B00 §10-7）。
