# B02 · 配置系统与双模式抽象

> 依赖规格：B00（唯一权威）。本文定义配置的读取/校验/热更新，以及 `ModeAdapter` 双模式抽象。
> 版本：v0.1.0　|　日期：2026-10-13　|　对应测试：C02（配置与模式切换测试）

> **v0.2.0 增量（必读）**：B00 v0.2 新增两组配置键，本文的 `GuardianConfig` 需一并覆盖——
> ① `qq.check_interval`（默认 1200 秒，QQ 登录态独立巡检间隔）；
> ② `lifecycle.*`（`enabled / levels[template_list] / max_uptime_hours / force_sleep_on_deadline / sleep_targets / inject_mode / inject_cooldown_sec / sleep_duration_min / post_sleep_notify`）。
> `lifecycle.levels` 为**前端可配的等级表**，每项含 `id/name/after_hours/prompt/action`，校验规则见 `B15` 第 8 节。完整设计见 `B15_生命周期等级与自主睡眠机制.md`。

## 1. 目标

1. 建立「schema 定义 → AstrBotConfig 读取 → `GuardianConfig` 只读视图」三层配置链，杜绝散落的 `self.config["x"]`。
2. 用 `GuardianConfig.validate()` 在启动与配置变更时集中校验，错误不静默。
3. 用 `ModeAdapter` 把「服务器模式」与「ROS2 模式」的探针/动作差异收口到子类，`HealthEngine` 不感知模式。
4. 明确「配置」与「运行时状态」的边界，禁止用状态文件篡改配置。

**产出**：`core/config.py`、`modes/base.py`、`modes/factory.py` 完整实现；`modes/server.py`、`modes/ros2.py` 骨架。

---

## 2. 配置分层

```
_conf_schema.json   →   AstrBotConfig(self.config)   →   GuardianConfig（只读视图）
  契约层：键/类型/默认值      存取层：dict-like + save_config()    视图层：dataclass + validate() + 派生属性
```

| 层 | 职责 | 禁止 |
| --- | --- | --- |
| schema | 声明键与默认值；`options` 做 UI 约束 | 写业务逻辑 |
| AstrBotConfig | 读写与持久化；`save_config()` | 在业务代码里直接散用 |
| GuardianConfig | 默认值合并、类型校验、只读派生 | 持有可变运行时状态 |

**热更新**：WebUI 保存后触发配置变更事件，插件重建视图 `GuardianConfig.from_astrbot_config(raw)`，再按第 10 节矩阵决定是否重启引擎/重载模式。运行时状态（档位、冷却、计数）**不**写回配置，见第 8 节。

## 3. core/config.py 完整代码

`DEFAULTS` 是嵌套段默认值的**单一来源**；嵌套段以 `SimpleNamespace` 承载（轻量、支持 `cfg.memory.warn_mb` 属性访问），顶层视图是 dataclass。

```python
# core/config.py
from __future__ import annotations
from dataclasses import dataclass, field
from types import SimpleNamespace
from typing import Any

VALID_MODES = ("server", "ros2")
VALID_PROFILES = ("normal", "night", "maintenance", "aggressive")
VALID_SEVERITIES = ("info", "warn", "crit", "fatal")
VALID_RELOGIN = ("restart_container", "webui_quick_login", "disabled")
VALID_SELF_RESTART = ("watchdog", "docker_api", "disabled")
VALID_ROS2_BACKENDS = ("local", "docker_exec")
# 嵌套段默认值（与 _conf_schema.json 严格一致，作为唯一来源）
DEFAULTS: dict[str, dict[str, Any]] = {
    "docker": {"socket_path": "/var/run/docker.sock", "api_version": "v1.44", "use_cli_fallback": False},
    "containers": {"astrbot": "astrbot", "napcat": "napcat", "managed": []},
    "qq": {"onebot_http_base": "http://napcat:3000", "access_token": "", "relogin_method": "restart_container", "relogin_cooldown": 300, "max_relogin_per_hour": 4},
    "memory": {"warn_mb": 700, "crit_mb": 1100, "growth_warn_mb_per_hour": 80.0, "samples": 10, "restart_on_leak": False, "leak_cooldown": 3600},
    "schedule": {"daily_restart_enabled": False, "daily_restart_cron": "0 4 * * *", "daily_restart_targets": []},
    "ros2": {"exec_backend": "local", "docker_container": "", "expected_nodes": [], "expected_topics": [], "topic_hz_min": 0.0, "node_restart_commands": {}},
    "notify": {"umo_list": [], "min_severity": "warn", "rate_limit_sec": 60},
    "safety": {"allowed_containers": [], "protected_containers": ["astrbot"], "action_cooldown_sec": 600, "max_actions_per_hour": 6, "circuit_breaker_window_sec": 1800, "allow_self_restart": False, "self_restart_strategy": "watchdog"},
    "llm_tools": {"enabled": True, "require_admin": True},
    "night_profile": {"maintenance_restart_cron": "0 4 * * *", "mute_below_severity": "warn"},
}


def _coerce(value: Any, default: Any) -> Any:
    """按默认值类型强转；缺失/非法回落默认值。"""
    if value is None:
        return default
    try:
        if isinstance(default, bool):
            return value if isinstance(value, bool) else str(value).lower() in ("1", "true", "yes", "on")
        if isinstance(default, int):
            return int(value)
        if isinstance(default, float):
            return float(value)
        if isinstance(default, list):
            return (value if isinstance(value, (list, tuple))
                    else [s.strip() for s in str(value).split(",") if s.strip()])
        if isinstance(default, dict):
            return value if isinstance(value, dict) else {}
        return str(value)
    except (TypeError, ValueError):
        return default


def _section(name: str, raw: Any) -> SimpleNamespace:
    src = raw if isinstance(raw, dict) else {}
    return SimpleNamespace(**{k: _coerce(src.get(k), v) for k, v in DEFAULTS[name].items()})


@dataclass
class GuardianConfig:
    """只读配置视图；业务代码只依赖本类型。"""
    enabled: bool = True
    mode: str = "server"
    profile: str = "normal"
    check_interval: int = 60
    dry_run: bool = True
    os_hint: str = "arch"
    docker: Any = field(default_factory=lambda: _section("docker", {}))
    containers: Any = field(default_factory=lambda: _section("containers", {}))
    qq: Any = field(default_factory=lambda: _section("qq", {}))
    memory: Any = field(default_factory=lambda: _section("memory", {}))
    schedule: Any = field(default_factory=lambda: _section("schedule", {}))
    ros2: Any = field(default_factory=lambda: _section("ros2", {}))
    notify: Any = field(default_factory=lambda: _section("notify", {}))
    safety: Any = field(default_factory=lambda: _section("safety", {}))
    llm_tools: Any = field(default_factory=lambda: _section("llm_tools", {}))
    night_profile: Any = field(default_factory=lambda: _section("night_profile", {}))
    @classmethod
    def from_astrbot_config(cls, raw: Any) -> "GuardianConfig":
        """从 AstrBotConfig 构造只读视图；缺失键回落 DEFAULTS。"""
        def g(key: str, default: Any = None) -> Any:
            try:
                v = raw.get(key, default)
            except Exception:  # noqa: BLE001
                return default
            return default if v is None else v
        return cls(
            enabled=_coerce(g("enabled"), True), mode=_coerce(g("mode"), "server"),
            profile=_coerce(g("profile"), "normal"), check_interval=_coerce(g("check_interval"), 60),
            dry_run=_coerce(g("dry_run"), True), os_hint=_coerce(g("os_hint"), "arch"),
            **{name: _section(name, g(name, {})) for name in DEFAULTS},
        )
    def validate(self) -> list[str]:
        """返回错误列表，空列表表示通过；完整规则见第 9 节。"""
        e: list[str] = []
        if self.mode not in VALID_MODES:
            e.append(f"mode 非法: {self.mode!r}")
        if self.profile not in VALID_PROFILES:
            e.append(f"profile 非法: {self.profile!r}")
        if self.check_interval < 5 or not 0 < self.memory.warn_mb < self.memory.crit_mb \
                or self.memory.samples < 2:
            e.append("check_interval / memory 阈值或样本数非法")
        if self.qq.relogin_method not in VALID_RELOGIN:
            e.append("qq.relogin_method 非法")
        if self.safety.self_restart_strategy not in VALID_SELF_RESTART:
            e.append("safety.self_restart_strategy 非法")
        if self.notify.min_severity not in VALID_SEVERITIES:
            e.append("notify.min_severity 非法")
        if self.ros2.exec_backend not in VALID_ROS2_BACKENDS or (
                self.ros2.exec_backend == "docker_exec" and not self.ros2.docker_container):
            e.append("ros2 后端/容器配置非法")
        if not self.containers.astrbot or self.containers.astrbot in self.containers.managed:
            e.append("containers.astrbot 非法或出现在 managed 中")
        return e
    @property
    def action_allowlist(self) -> set[str]:
        """动作白名单 = managed ∪ safety.allowed_containers（B00 安全红线 2）。"""
        return set(self.containers.managed) | set(self.safety.allowed_containers)
    @property
    def monitored_targets(self) -> list[str]:
        """server 模式默认监控目标：本体 + 协议端 + managed。"""
        out = [self.containers.astrbot, self.containers.napcat]
        out += [x for x in self.containers.managed if x not in out]
        return out
    @property
    def self_restart_enabled(self) -> bool:
        return bool(self.safety.allow_self_restart and self.safety.self_restart_strategy != "disabled")
```

## 4. 双模式抽象设计

`ModeAdapter` 是「模式」的唯一落点（B00 第 4 节）。`HealthEngine` 只持有当前适配器，通过它取探针与动作，**不写 `if mode == "ros2"`**。

| 成员 | 语义 |
| --- | --- |
| `NAME` / `name` | 模式名（`server` / `ros2`），与配置 `mode` 对应 |
| `PROBE_NAMES` / `ACTION_KINDS` | 本模式探针名 / 动作 kind 清单（供 `describe` 与文档） |
| `build_probes()` / `build_actions()` | 构造探针实例列表 / 构造 kind → Action 映射 |
| `describe()` | 人类可读描述，供 `/guardian status` 与诊断 |

**构造约定**：探针 `Probe(config, deps, target=...)`；动作 `Action(config, deps)`。`deps` 由引擎注入（`dockerclient`、`notifier`、`bus`、`state`、`safety`、`shell`），使探针/动作可 mock（决策 D4）。

## 5. modes/base.py 与 modes/factory.py 完整代码

```python
# modes/base.py
from abc import ABC, abstractmethod
from typing import Any

from ..core.config import GuardianConfig


class ModeAdapter(ABC):
    """守护模式适配器：决定启用哪些探针与动作（B00 第 4 节）。"""

    NAME: str = ""
    PROBE_NAMES: tuple[str, ...] = ()
    ACTION_KINDS: tuple[str, ...] = ()

    def __init__(self, config: GuardianConfig, deps: dict[str, Any]):
        self.config, self.deps = config, deps

    @property
    def name(self) -> str:
        return self.NAME

    @abstractmethod
    def build_probes(self) -> list:
        """构造本模式探针实例列表。"""

    @abstractmethod
    def build_actions(self) -> dict:
        """构造 kind -> Action 映射。"""

    def describe(self) -> str:
        return f"mode={self.name} | 探针={list(self.PROBE_NAMES)} | 动作={list(self.ACTION_KINDS)}"
```

```python
# modes/factory.py
from typing import Any

from ..core.config import GuardianConfig
from .base import ModeAdapter
from .ros2 import Ros2Mode
from .server import ServerMode

_REGISTRY: dict[str, type[ModeAdapter]] = {"server": ServerMode, "ros2": Ros2Mode}


def create_mode(mode: str, config: GuardianConfig, deps: dict[str, Any]) -> ModeAdapter:
    """按模式名构造适配器；未知模式抛 ValueError（切换前已 validate）。"""
    cls = _REGISTRY.get(mode)
    if cls is None:
        raise ValueError(f"未知守护模式: {mode!r}，可用: {sorted(_REGISTRY)}")
    return cls(config, deps)
```

## 6. modes/server.py 与 modes/ros2.py 骨架

两文件结构相同：`import` 各自探针/动作模块（路径见 B01 目录结构）后，实现 `ModeAdapter` 三个成员。

```python
# modes/server.py —— 服务器模式：Docker 容器 + QQ 协议端 + 资源（B04/B05/B06）
from ..core.config import GuardianConfig
from .base import ModeAdapter


class ServerMode(ModeAdapter):
    NAME = "server"
    PROBE_NAMES = ("docker_daemon", "container_health", "container_memory", "qq_login", "self_health")
    ACTION_KINDS = ("restart_container", "start_container", "qq_relogin", "set_profile", "notify")

    def __init__(self, config: GuardianConfig, deps: dict):
        super().__init__(config, deps)

    def build_probes(self) -> list:
        cfg, t = self.config, self.config.monitored_targets
        return [DockerDaemonProbe(cfg, self.deps), ContainerHealthProbe(cfg, self.deps, targets=t),
                ContainerMemoryProbe(cfg, self.deps, targets=t), QQLoginProbe(cfg, self.deps),
                SelfHealthProbe(cfg, self.deps)]

    def build_actions(self) -> dict:
        return {"restart_container": RestartContainerAction(self.config, self.deps),
                "start_container": StartContainerAction(self.config, self.deps),
                "qq_relogin": QQReloginAction(self.config, self.deps),
                "set_profile": SetProfileAction(self.config, self.deps),
                "notify": NotifyAction(self.config, self.deps)}
```

## 7. 模式切换流程（7 步）

切换由 `/guardian mode <m>` 或 LLM 工具 `guardian_set_mode` 触发，统一走 `HealthEngine.switch_mode(new_mode)`：

| 步 | 动作 | 要点 |
| --- | --- | --- |
| 1 | **停表** | `scheduler.pause()`，取消下一次 tick，防止切换中并发巡检 |
| 2 | **等待在途** | `await engine.wait_idle(timeout=30)`；超时记录 WARN 并强制继续 |
| 3 | **释放旧模式** | 对旧探针逐个 `await probe.close()`（关连接/会话） |
| 4 | **构建新模式** | `create_mode(...)` → `build_probes()` + `build_actions()` |
| 5 | **重置冷却/熔断** | `safety.reset()` 清空 cooldown 与 breaker（换模式后旧窗口无意义） |
| 6 | **落盘** | `state.set("mode", new_mode)` + `state.set("mode_switched_at", ts)` + `save()` |
| 7 | **通知 + 起表** | `notifier.dispatch(...)` 发回执；`scheduler.resume(interval_for(profile))` |

**实现骨架**：`switch_mode()` 依次执行 `scheduler.pause()` → `await wait_idle(timeout=30)` → 逐个 `await probe.close()` → `create_mode(...)` 重建 `self._probes/_actions` → `deps["safety"].reset()` → `state.set/save()` → `notifier.dispatch_text()` → `scheduler.resume(interval_for(profile))`。完整代码见 B03。

## 8. 配置与运行时状态的边界

| 类别 | 来源 | 是否持久化 | 示例 |
| --- | --- | --- | --- |
| **静态配置** | `_conf_schema.json` / WebUI | AstrBot 持久化 | `containers.*`、`safety.*`、`docker.*` |
| **运行时可覆盖状态** | 命令 / LLM 工具 | `StateStore` 持久化到 `data/` | `profile`、`mode`、`night_until` |
| **纯运行时瞬时状态** | 引擎 | 仅内存（重启即清） | 在途巡检标志、本次 `ProbeResult` 列表 |
| **冷却/熔断窗口** | `SafetyGuard` | 落盘（防重启绕过冷却） | `cooldown[target]`、`action_count[window]` |

1. `profile` 与 `mode` 属「可运行时覆盖」：命令改 `StateStore`，**不写回** `_conf_schema.json`（避免 WebUI 与运行时打架）。
2. 启动优先级：`StateStore` 中已持久化的 `mode`/`profile` **覆盖**配置默认值（夜间档位跨重启保持）。
3. 冷却/熔断窗口必须落盘，否则容器重启即可绕过冷却（风险 R1）；校验只在「配置变更」与「启动」时执行，运行时覆盖的 `profile`/`mode` 写入前单独校验枚举。

## 9. 校验规则表

| 键 | 类型 | 范围/约束 | 默认 | 失败行为 |
| --- | --- | --- | --- | --- |
| `enabled` | bool | — | true | false 时不启动引擎 |
| `mode` | str | ∈ {server, ros2} | server | 校验失败 → 拒绝启用引擎 |
| `profile` | str | ∈ 4 档位 | normal | 校验失败 → 拒绝启用引擎 |
| `check_interval` | int | ≥ 5 | 60 | 越界 → 校验失败 |
| `docker.socket_path` | str | 非空 | /var/run/docker.sock | 不存在 → 启动自检告警，可降级 CLI |
| `docker.api_version` | str | 形如 vX.YY | v1.44 | 协商失败 → 自动降级探测 |
| `containers.astrbot` | str | 非空 | astrbot | 空 → 校验失败 |
| `containers.managed` | list[str] | 不含本体 | [] | 含本体 → 校验失败 |
| `qq.relogin_method` | str | ∈ 三值 | restart_container | 非法 → 校验失败 |
| `qq.relogin_cooldown` | int | ≥ 0 | 300 | 负值 → 校验失败 |
| `memory.warn_mb` / `crit_mb` | int | 0 < warn < crit | 700 / 1100 | 违反 → 校验失败 |
| `memory.growth_warn_mb_per_hour` | float | ≥ 0 | 80 | 负值 → 回退 80 |
| `memory.samples` | int | ≥ 2 | 10 | 违反 → 校验失败 |
| `ros2.exec_backend` / `docker_container` | str | 后端 ∈ {local, docker_exec}；docker_exec 时容器名非空 | local / "" | 非法 → 校验失败 |
| `notify.min_severity` | str | ∈ 4 级别 | warn | 非法 → 校验失败 |
| `safety.max_actions_per_hour` | int | ≥ 1 | 6 | 违反 → 校验失败 |
| `safety.action_cooldown_sec` | int | ≥ 0 | 600 | 负值 → 校验失败 |
| `safety.self_restart_strategy` | str | ∈ 三值 | watchdog | 非法 → 校验失败 |
| `night_profile.mute_below_severity` | str | ∈ 4 级别 | warn | 非法 → 校验失败 |

**失败行为总则**：`validate()` 非空 → 启动路径**拒绝启用引擎**并 FATAL 通知；热更新路径**保留旧视图**并通知错误。

## 10. 配置变更生效矩阵

| 键 | 生效方式 | 说明 |
| --- | --- | --- |
| `enabled` | 热生效 | true→false 停引擎；false→true 启动（幂等） |
| `mode` | 走模式切换流程 | 等价于 `/guardian mode`，第 7 节 7 步 |
| `profile` | 热生效 | 重排定时器间隔 + 调整静默级别 |
| `check_interval` | 热生效 | `scheduler.resume(interval)` |
| `dry_run` / `os_hint` | 热生效 | 下一次动作/诊断读取 |
| `docker.*` | **需重载** | 重建 `dockerclient`（socket/版本变更） |
| `containers.*` | **需重载** | 探针目标集合变化，需重建探针 |
| `qq.*` | 连接类**需重载**；冷却/熔断热生效 | 重建 OneBot 客户端 / `SafetyGuard` 每动作读取 |
| `memory.*` | 热生效 | 探针在 `check()` 时读配置 |
| `schedule.*` | 热生效 | 重排 cron-lite 任务 |
| `ros2.*` | **需重载**（当前为 ros2 模式时） | 重建 ROS2 探针与恢复映射 |
| `notify.*` | 热生效 | 通知器每次推送读配置 |
| `safety.*` | 热生效 | 但 `protected_containers` / `allow_self_restart` 变更建议重载 |
| `llm_tools.*` | **需重载** | 工具注册/注销在加载期完成 |
| `night_profile.*` | 热生效 | 进入夜间档位时读取 |

> 「需重载」= WebUI 重载插件，或触发 `HealthEngine.reload_config()`（内部重建 `dockerclient`、探针与动作）。

## 11. 验收标准（对应 C02）

| 编号 | 判据 | 方法 |
| --- | --- | --- |
